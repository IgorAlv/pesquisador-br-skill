# Perfis de escrita

Cada arquivo descreve a voz de um(a) autor(a): o que manter, o que calibrar e o que evitar.
Foram extraídos de textos reais dessas pessoas e servem para redigir ou revisar no estilo
delas, sem cara de texto gerado.

## Como usar

1. Quando o usuário disser de quem é o texto (ou que está escrevendo no estilo de alguém
   listado aqui), carregue o perfil correspondente antes de redigir ou revisar.
2. O perfil **prevalece** sobre as regras gerais de estilo da skill (por exemplo, sobre a
   lista de conectivos ou sobre a 1ª pessoa no memorial). Regras ABNT e o Integrity Gate
   continuam valendo sempre.
3. Combine com `../estilo-anti-ia.md`.
4. Sugestões de estilo são propostas: o(a) autor(a) decide cada uma.
